# Changelog

## 1.0.0

- Initial public SDK for the Stedi Healthcare API on .NET 6.
- Covers payers, providers, enrollments, eligibility (JSON, raw X12, SOAP, batch, PDF), insurance discovery, coordination of benefits, claim submission, attachments, 277CA, 835 ERA, claim status, transactions, and events.
- Models are generated from official Stedi OpenAPI specifications and wrapped in an idiomatic C# client.
